FAQ Interaktif (jQuery)

1. Apa itu jQuery?
jQuery adalah library JavaScript untuk memudahkan manipulasi HTML, CSS, dan event.
2. Bagaimana cara kerja .click()?
.click() digunakan untuk menangani event klik pada elemen.
3. Apa fungsi .toggle()?
.toggle() digunakan untuk menampilkan atau menyembunyikan elemen secara bergantian.
4. Apa itu selector jQuery?
Selector digunakan untuk memilih elemen HTML yang ingin dimanipulasi.
5. Apa itu event hover?
Event hover terjadi ketika mouse berada di atas dan keluar dari elemen.
